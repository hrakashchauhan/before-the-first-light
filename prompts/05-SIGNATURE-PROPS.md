# Prompt 05 — Signature preparation objects

Add believable thickness, handmade irregularity, correct scale and interaction anchors. Make drying/preparation stages visually distinguishable. Do not invent exact ritual/craft details; use documented references and mark uncertain details for review. No photo textures or image planes.
