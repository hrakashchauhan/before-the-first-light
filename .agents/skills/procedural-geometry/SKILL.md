# Procedural geometry skill

For each prop: define silhouette, dimensions, pivot, material slots, interaction anchor and LOD/performance needs. Build a reusable geometry function/component with deterministic parameters. Avoid random variation during React render; use seeded values. Check normals, thickness, scale, UV assumptions and contact points. Reuse geometry where possible.
