# Performance optimisation skill

Measure before changing. Record viewport, DPR, FPS/frame time, draw calls and console output. Check repeated geometry/material allocation, shadow cost, post-processing, unnecessary React updates and event listeners. Prefer instancing, shared materials, compact scenes and DPR cap. Do not claim optimisation without before/after measurements.
