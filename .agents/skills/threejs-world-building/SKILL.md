# Three.js world-building skill

- Read visual style and performance standards.
- Block out scale and navigation before detail.
- Build ground, courtyard, house, lane, pond and ghat as actual meshes.
- Use coherent world units and stable object IDs.
- Add material variation with procedural colour/vertex colour rather than photo textures.
- Use instancing for repeated foliage, lamps or grain.
- Test camera framing, resize and player readability.
- Check grounding, intersections, normals, shadows and draw calls.
- Do not use image planes or generated images.
