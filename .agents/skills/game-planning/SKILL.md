# Game planning skill

1. Read the vision, GDD, roadmap and risk register.
2. Identify the current milestone and its acceptance criteria.
3. Define one user-visible outcome.
4. List files to inspect and expected files to change.
5. Identify dependencies and cultural review needs.
6. Implement the smallest complete slice.
7. Run tests/build/browser verification.
8. Update development log and propose one next milestone.

Never turn a milestone into a broad rewrite. Prefer a complete 10-minute vertical slice over many disconnected systems.
