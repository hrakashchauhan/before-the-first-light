# 18 — Release readiness checklist

## Product
- [ ] New Game and Continue work.
- [ ] First objective is understandable.
- [ ] All required quests can be completed.
- [ ] No softlocks.
- [ ] Save/load works and handles invalid data.
- [ ] Pause/settings/language/subtitles work.
- [ ] Finale can be completed.

## Technical
- [ ] Typecheck passes.
- [ ] Automated tests pass.
- [ ] Production build passes.
- [ ] Browser console has no unexplained errors.
- [ ] Tested on the target Windows laptop.
- [ ] Performance observations recorded.
- [ ] Responsive behaviour checked at target viewport.

## Art and sound
- [ ] No AI-generated image or photo background.
- [ ] Major environment elements are real 3D geometry.
- [ ] No floating/intersecting critical props.
- [ ] Audio levels and mute work.
- [ ] All external asset rights recorded.

## Culture and safety
- [ ] Ritual details reviewed by knowledgeable local people.
- [ ] Bhojpuri dialogue/music reviewed and consented.
- [ ] Family-specific practices labelled as such.
- [ ] No unsafe fasting/fire/crowd gameplay.
- [ ] Shared labour and care are represented.

## Release
- [ ] README updated.
- [ ] Credits and attributions complete.
- [ ] Version number set.
- [ ] Known limitations disclosed.
- [ ] Final Git commit/tag created.
