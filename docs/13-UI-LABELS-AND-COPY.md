# 13 — UI labels, prompts and copy

## Screen labels
- `New Game`
- `Continue`
- `Settings`
- `Credits`
- `Back`
- `Resume`
- `Pause`
- `Journal`
- `Objectives`
- `Inventory`
- `Language`
- `Subtitles`
- `Music`
- `Sound Effects`

## Interaction prompt pattern
`[E] Talk`  
`[E] Inspect`  
`[E] Help`  
`[E] Pick up`  
Use an action verb. Do not show a prompt when the target is out of range or blocked.

## HUD
Keep it minimal:
- Current chapter/day label.
- One primary objective.
- Small contextual interaction prompt.
- Optional journal indicator.
Do not cover the village with permanent panels.

## Quest copy pattern
**Title:** short action-oriented phrase.  
**Description:** one sentence explaining why it matters.  
**Steps:** no more than three visible steps at once.  
**Completion:** acknowledge contribution and show a world change.

## Voice
Warm, simple, observant and respectful. Avoid exaggerated “epic” language for ordinary household work. Avoid treating the festival as a checklist detached from people.
