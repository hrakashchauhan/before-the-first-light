# 19 — Risk register

| Risk | Likelihood | Impact | Mitigation |
|---|---|---|---|
| Scope grows too large | High | High | Lock MVP; one milestone at a time |
| Laptop performance is low | Medium | High | Compact scene, DPR cap, instancing, profile early |
| Cultural inaccuracies | Medium | High | Local validation ledger; remove unverified claims |
| AI changes too many files | High | High | File ownership, small prompts, Git checkpoints |
| Dependency mismatch | Medium | Medium | Inspect package versions; stable versions only |
| Broken keyboard listeners | Medium | Medium | Central input manager; cleanup; tests |
| Save format changes | Medium | Medium | Schema version and safe migration |
| Copyrighted music/asset | Medium | High | Rights ledger; original/licensed material only |
| Procedural props look generic | Medium | Medium | Reference study, silhouettes, iterative screenshots |
